# Code of Conduct

Be respectful, specific and constructive.

This project follows the spirit of the Contributor Covenant:

- Use welcoming and inclusive language.
- Respect differing viewpoints and experience levels.
- Give actionable technical feedback, not personal criticism.
- Do not harass, discriminate, threaten or publish private information.
- Assume good faith while holding a high bar for correctness and safety.

Maintainers may remove comments, close issues or restrict participation when behaviour makes collaboration unsafe or unproductive.

Report conduct concerns privately through GitHub Security Advisories or by contacting a maintainer.
